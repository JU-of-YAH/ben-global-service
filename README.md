# BEN GLOBAL SERVICE

Base initiale du nouveau site.

## Installation
npm install
npm run dev

## Production
npm run build

Le dossier de sortie est `dist`.

## Supabase
1. Créer le projet Supabase.
2. Exécuter `supabase/schema.sql`.
3. Copier `.env.example` vers `.env`.
4. Renseigner les variables Supabase.
5. Ajouter ensuite Auth, Storage et les fonctions admin.

Les véhicules de `src/data/vehicles.ts` sont des données de démonstration.
